🌿 Kindred

A private personal automation, used only by its owner.

Kindred is a personal assistant that runs on its owner's own computer. It connects a private Discord server to the owner's own tools so everyday tasks (logging expenses, organizing notes, and managing calendar events) can be done by sending a message. It is not a public service: no one else can sign up, and it only accesses the Google account of the person who runs it.

What it uses Google access for

  • Google Calendar: reads upcoming events to post reminders and show them in the owner's Discord server, and creates, updates, or deletes an event only after the owner confirms in Discord.
  • Google Sheets: reads and adds rows in the owner's personal finance spreadsheet.

Details about how this data is handled are in the privacy policy.
