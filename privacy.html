Kindred Privacy Policy

Effective September 15, 2026

Kindred is a private personal automation that runs on its owner's own computer. It has a single user, its owner, and accesses only that owner's own Google account. It is not offered to the public, and no one else can sign in to it.

Google data it accesses

  • Google Calendar: event titles, times, locations, and descriptions for the owner's calendar. Events are created, changed, or deleted only after the owner explicitly confirms in their private Discord server.
  • Google Sheets: the owner's personal finance spreadsheet, which Kindred reads and adds rows to.

How the data is used

  • To post the owner's upcoming events and reminders, and answers about the owner's own finances, in the owner's private Discord server.
  • To mirror upcoming calendar events as events in that same private Discord server.
  • To process the owner's own requests. Some text, such as the owner's messages and spreadsheet rows needed to answer a question, is sent to Anthropic's Claude API to understand the request and write a reply.

What it does not do

  • It does not sell, rent, or share Google data with anyone, or use it for advertising.
  • It does not transfer Google data to third parties except the services listed above, and only to carry out the owner's own requests.
  • It does not use Google data to train AI models.

Kindred's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

Access tokens are stored encrypted by the automation software (n8n) on the owner's computer. Workflow data stays on that computer and in the owner's private Discord server and personal notes. No separate server or database collects this data.

Removing access

Access can be revoked at any time from Google Account → Third-party apps & services. Revoking it stops all further access immediately.

Contact

This is a personal project. Questions can be sent to the owner through the GitHub account that hosts this page.
